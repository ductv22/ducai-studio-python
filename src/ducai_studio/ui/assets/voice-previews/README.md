# Voice preview assets

These WAV files are short catalog auditions generated from the exact voice shown
in DUCAI STUDIO. They are not production cache and do not contain user media.

- `vi_VN-vais1000-medium.wav`: official Piper Vais1000 Medium, CC BY 4.0.
- `vi_VN-vivos-x_low.wav`: official Piper VIVOS X-Low, CC BY-NC-SA 4.0.
- `vieneu-*.wav`: VieNeu-TTS v3 Turbo 3.8.1 built-in presets, CC BY-NC 4.0,
  non-commercial use.

All clips are PCM WAV, contain distinct Vietnamese text and are between 5 and 8
seconds. Regenerate from licensed local runtimes with
`scripts/generate-voice-previews.py`; never substitute another speaker under an
existing voice name.
